# 1. Record architecture decisions

- Status: accepted
- Date: 2026-11-19

## Context

Ichnote is an open-source project whose design (`docs/DESIGN.md`) will evolve. Decisions and
their reasons need to stay discoverable for future contributors.

## Decision

Record significant architecture decisions as short Markdown files in `docs/adr/`, numbered
sequentially (`NNNN-title.md`), using the format: Status, Date, Context, Decision, Consequences.
ADRs are written in English. Superseded ADRs are kept and marked as such.

## Consequences

Decisions are reviewable in pull requests alongside the code that implements them.
